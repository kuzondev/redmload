# Newspaper hand atlas

Generated with the built-in image_gen tool. Transparent RGBA atlas, 1536×1024 pixels, four columns and two rows. Left hand on the first row, right hand on the second. The Vue animation selects the four poses with CSS background positions, synchronized with the configured page-turn duration. This is an animated sprite overlay rather than a rigged 3D character model.

Prompt: Production game UI sprite atlas on a genuinely transparent background. Exactly four columns by two rows; left hand top row, right hand bottom row. Four poses: relaxed newspaper grip, thumb/index pinch, inward reach pulling a page, relaxed release. Same gloves, proportions, camera scale and wrist positions in all poses. No paper, text, background, grid lines or extra limbs.
